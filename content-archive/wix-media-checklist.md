**Drop as** path; any file extension is fine (e.g. `shoplifting-surge/audio.mp3`). A path ending in `/`
means a folder of several files. Originals at full resolution are best: I'll optimize them.

in the position the media sat on the Wix page. The Wix ID is there to help you find the right file.

backgrounds and the background videos on Home, JRNL 3180, EPS and Audio pages. The BCI logo on the Wix home page
was also skipped (third-party trademark; ask if you want it).
